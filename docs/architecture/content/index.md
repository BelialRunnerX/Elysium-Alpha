# Elysium

Welcome to **Elysium** — the living architecture and design wiki for a browser-based roguelite set in the Sleeping Empire universe.

## What is Elysium?

Elysium is a 2D roguelite built with an **Entity Component System (ECS)** architecture. The player is an ambitious wanderer pursuing power through exploration, combat, and gear progression.
