# Elysium

**Elysium** is the architectural and design documentation site for a browser-based roguelite set in the Sleeping Empire universe.

## Features

- Deep ECS-based architecture documentation
- Procedural universe generation concepts
- Detailed systems for Armor, Weapons, and Psionics
- Interactive 2D map with 3D planet viewer integration
- Randomized loot and encounter systems

## Tech Stack

- [Quartz](https://quartz.jzhao.xyz/) – Static site generator for Obsidian-style vaults
- Markdown with wikilinks and graph view
- Deployed on GitHub Pages

## Local Development

```bash
npm install
npm run start
```

## Deployment

The site is automatically deployed to GitHub Pages via GitHub Actions when changes are pushed to `main`.
