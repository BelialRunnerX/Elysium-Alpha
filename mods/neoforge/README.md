# Elysium

A Minecraft Forge mod that combines **Apotheosis**, **Reforged/Tierify**, and **Silent Gear** into one deep gear progression system inspired by the Sleeping Empire universe.

## Core Features (Planned)

- Deep tiered armor and weapons (Common → Legendary)
- Elemental affinities (Void, Plasma, Neural, Dimensional, Kinetic)
- Rune socketing system with meaningful effects
- Flat + percentage stat system
- Psionic abilities integrated with gear
- Integration with Apotheosis enchanting and spawners
- Modular gear inspired by Silent Gear

## Current Status

- Basic Forge mod skeleton
- Project structure ready for development

## Building

```bash
./gradlew build
```
